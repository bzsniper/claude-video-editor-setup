# Claude video editor setup

Two setup files that turn Claude Code into a video editor on your own computer. Each one interviews you first, then builds a setup around your footage, your editing program (or none) and your taste.

| File | What it sets up |
| --- | --- |
| [SHORTS-EDITOR-SETUP.md](SHORTS-EDITOR-SETUP.md) | A short-form editor with a private review app for approving clips |
| [LONGFORM-EDITOR-SETUP.md](LONGFORM-EDITOR-SETUP.md) | A long-form editor that cuts, checks and exports your video |

## How to use one

1. Open the file above and click the **Download raw file** button (the down arrow at the top right of the file).
2. Put it in a new, empty folder.
3. Open that folder in Claude Code.
4. Say: **"Read SHORTS-EDITOR-SETUP.md and set this up with me."** For long-form, use the other file name.

You can use either one on its own. Tested on a Mac; not yet tested on Windows or Linux.
